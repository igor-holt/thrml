## 2024-05-18 - Accessible Data Tables
**Learning:** Data tables in this app, like the one in `TelemetryTimeline.tsx`, require explicit `<caption>` elements for screen readers. Since utility classes like `.sr-only` are not available in `app/globals.css`, visually hiding the caption while retaining it for screen readers requires explicit inline CSS string structures (e.g. `clip: 'rect(0, 0, 0, 0)'`). In addition, table header cells (`<th>`) require explicit `scope="col"` attributes to ensure column-row associations are explicitly mapped for accessibility.
**Action:** When creating or modifying data tables, ensure a `<caption>` element is included right after the `<table>` start tag, hiding it visually with standard inline clipping CSS, and add `scope="col"` to all header `<th>` tags.
