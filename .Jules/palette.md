## 2026-04-17 - Visually Hidden Elements for Accessibility without Utility Classes
**Learning:** In Next.js repositories without utility frameworks like Tailwind CSS, and where global CSS files (like `app/globals.css`) do not define `.sr-only` classes, providing context to screen readers (e.g., table captions) requires comprehensive inline styling to hide the element visually without breaking layout or removing it from the accessibility tree.
**Action:** Use explicit inline CSS styles: `style={{ position: 'absolute', width: '1px', height: '1px', padding: 0, margin: '-1px', overflow: 'hidden', clip: 'rect(0, 0, 0, 0)', whiteSpace: 'nowrap', borderWidth: 0 }}` for visually hidden text when `.sr-only` is unavailable. Always explicitly define structural relationships, such as adding `scope="col"` to table header `<th>` cells for data tables.
