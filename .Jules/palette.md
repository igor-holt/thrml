## 2024-07-25 - Backend-Only Repository UX Guidelines
**Learning:** This repository (thrml) is exclusively a backend Python JAX library. There are no UI components, Next.js, React, or frontend templates to apply UX or accessibility enhancements to. Standard UX improvement tasks are fundamentally inapplicable in this environment.
**Action:** When acting as the Palette agent in a backend-only environment, acknowledge the absence of UI components and immediately halt execution to prevent polluting the codebase with irrelevant changes, satisfying the project's 'Zero UI' constraints.
