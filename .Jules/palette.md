## 2025-02-23 - Data Table Accessibility with Next.js Global CSS Limitations
**Learning:** Next.js applications in this codebase may lack utility classes for screen-reader-only elements (like `.sr-only` typically found in Tailwind CSS or Bootstrap). When adding captions to data tables for accessibility, if the design does not accommodate a visible caption, it must be visually hidden without breaking the layout or being truly hidden from screen readers (e.g., using `display: none` or `visibility: hidden` is incorrect).
**Action:** Use an extensive inline style object `{{ position: 'absolute', width: '1px', height: '1px', padding: 0, margin: '-1px', overflow: 'hidden', clip: 'rect(0, 0, 0, 0)', whiteSpace: 'nowrap', borderWidth: 0 }}` to visually hide the `<caption>` element while preserving screen reader accessibility. Do not assume utility classes are present without verifying `globals.css` or the CSS framework configuration.
