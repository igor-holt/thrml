## 2024-03-03 - Accessible visually hidden elements and data tables
**Learning:** The `app/globals.css` file should define a reusable utility class like `.sr-only` for visually hidden content. When elements (e.g., screen-reader captions for data tables) need to be visually hidden for accessibility without breaking layout, they should use a complete sr-only pattern (for example: `position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0, 0, 0, 0); white-space: nowrap; border: 0;`) instead of only `position: 'absolute', width: '1px', overflow: 'hidden'`. Additionally, all data tables must include `scope="col"` attributes on header cells (`<th>`) and a `<caption>` element for accessibility.
**Action:** Add a `.sr-only` utility to `app/globals.css` using a complete visually hidden pattern and use that class (or the equivalent full pattern) for all screen-reader-only elements. Ensure all table structures explicitly denote row/column scopes and contain captions.
