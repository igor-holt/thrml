## 2024-05-14 - Semantic Table Accessibility
**Learning:** Tables often miss structural accessibility features like scope for header cells (`<th>`) and captions (`<caption>`), reducing their usability with screen readers. Additionally, when the `globals.css` does not provide utility classes such as `.sr-only` to visually hide elements without breaking accessibility, we must use a specific set of inline CSS styles.
**Action:** Added `scope="col"` to all `<th>` tags in the Telemetry Timeline data table, and added a `<caption>` visually hidden with an inline style definition equivalent to `.sr-only` (`style={{ position: 'absolute', width: '1px', height: '1px', padding: 0, margin: '-1px', overflow: 'hidden', clip: 'rect(0, 0, 0, 0)', whiteSpace: 'nowrap', borderWidth: 0 }}`) to describe the table to screen readers without affecting the existing layout.
