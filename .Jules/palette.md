## 2025-05-14 - Backend repository learning
**Learning:** This repository (thrml) is a JAX library for probabilistic graphical models and exclusively backend-focused. There are no UI components (HTML, CSS, React, etc.) or Next.js setups, meaning standard UX and accessibility improvements are not applicable here.
**Action:** Recognize that UX/Accessibility checks are inherently inapplicable in pure math/algorithm/backend libraries. When in such repositories, avoid creating UX pull requests and halt execution after verifying no applicable UI enhancements exist.
